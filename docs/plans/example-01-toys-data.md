### 2.2 Tests are the spec

- Each step keeps all 478 of 01's run tests passing with their assertions as written. A test's body changes only where it reads, spawns or calls what the step removes, ported to its equivalent, each port counted in the evidence row.
- A computed value moves only where the step's Moves names it: within the asserting test's own tolerance, or by at most one fixed step in time (a look's first drawn frame by at most its frame's game time, Q15), 1 % in an amount or 1 px in a place, its old and new value listed. Any other changed outcome stops the step (§6). No test is deleted but one whose subject the step deletes.
- New tests only where a done-when names them; core's, the umbrella's and the kit's additions take their own crate's tests; no recipe (no genre claim).

### 2.3 Headless sprite sizes (Step 1)

- Core: `AssetRegistry::note_sprite_size(name, width, height, anchor)` interns `name` and records its size and anchor with no texture; `AssetRegistry::sprite_size(id)` and `sprite_anchor(id)` read a registered sprite's own (a sheet frame's its frame's), else the noted ones, else none (Q4). A noted sprite is not registered: `sprite(id)` and `get_sprite` stay `None`, so nothing draws it; registering it later wins.
- Umbrella: `Harness::note_sprite_sizes(path)` notes each sprite and sheet frame the manifest names, its size from its file's header (each file read once) and its anchor from the manifest, in sorted order as `register_sprites` takes them; it allocates no texture handle and registers no `engine_white`. `load_manifest` stays as it is: a harness calls it after the load (Q3).
- Kit: `prefab_centre`'s sprite branch reads `sprite_size` and `sprite_anchor`, the drawn centre at the prefab's scale, unturned and unflipped, as `sprite_centre` gives it for a registered sprite; with neither, zero, as today. `centre_of` still reads drawn sprites alone (Q5).
- No harness notes today, so no outcome moves anywhere: the kit's recipes, the template and 02 load as before.

### 2.4 01's art sizes and the missile's centre (Step 2)

- 01's harness builders (`tests/game/main.rs`, `tests/game/regime.rs`) call `note_sprite_sizes` after `load_manifest`; `with_sprites` stays for the bar.
