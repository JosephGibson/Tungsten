## 1. Method

### 1.1 The run

The run's folder, `perf-runs/20261107-big-session/jam/`, is local (`perf-runs/` is gitignored): the briefs (`briefs.md`), the five builders' logs (`<genre>.md`) with their command logs and shots, the merge (`merged.md`), the verifiers' files (`verify-1.md` … `verify-3.md`) and the doc rows' patch and notes (`docfix.*`). The games stay at `target/jam/games/<genre>/`, each with its `JAM-BRIEF.md` (the brief this run gave, the game built, the owner's brief for a repeat), built against the engine export `target/jam/engine` (`cad63fa5`) with one target dir, `target/jam/build`.

### 1.2 Row shape

`| ID | Friction | Kind | Genres | Evidence | Lines | Lacking | Fix | Destination |`

- **ID:** a builder's `<genre>.<n>`, the merge's `m<n>`, this register's `J-<n>` (`J-n` is `m-n`: verification moved no row's rank).
- **Kind:** the kind most of a row's builder rows carry, a tie going to the earlier in the ranking order (stuck, bug, guessed, kit-should-own, doc-gap, rule-conflict, wrong-turn).
- **Genres:** how many games hit it, then the builder rows.
- **Evidence:** `pl:`, `td:`, `rpg:`, `sh:`, `arpg:` are a game's folder (`target/jam/games/<genre>/`), `jam/` is the run's folder, a bare path is the engine at `cad63fa5`.
- **Lines:** the game code the fix would delete, summed from the cited ranges (per game in brackets; `~` where a builder estimated). A line sits in one row only, or one §4 entry.
- **Lacking:** what the engine, kit, template or docs lack, ending with its evidence: `none: <pattern>` (no match in `crates/*/src` or `api/*.txt`), the item that falls short (`path:line`), or `has: <item>` when the engine or kit already has it.
- **Fix:** the smallest change that deletes the game code or closes the gap.
- **Destination:** proposed, one of a doc fix now (`doc`), a phase 7 step (7.11–7.16), a Phase 8 step, `Later`, or a kit item with two genres' recipes (`kit`).

### 1.3 Ranking

Genres hit, descending; then Lines, descending; then Kind in §1.2's order.
