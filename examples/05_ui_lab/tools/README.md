# Example 05 sprites

`frame.png` (48×48, nine-slice insets 12 px, declared on the sprite entry), `icon.png` (32×32) and the inventory's ten item icons in `items/` (32×32 each: `draught`, `sword`, `cap`, `lantern`, `ore`, `herb`, `elixir`, `bow`, `mail`, `moonstone`, listed in the manifest as `ex05_item_<name>` with the `nearest` filter) are generated by `generate.py`, standard library only: it writes the PNG chunks by hand, so no Pillow is needed, and draws each item from a few flat shapes. Run it from the repository root:

```bash
python3 -B examples/05_ui_lab/tools/generate.py          # rewrite every file
python3 -B examples/05_ui_lab/tools/generate.py --check  # exit 1 when a file differs
```

The frame's four corners carry accent marks inside the inset, so a stretched nine-slice shows whether the corners kept their source size. Edit the generator, not the PNGs; the generated files are checked in because `just repo-check` covers them as ordinary assets.

## Pixel fixtures

`tests/fixtures/ui-visual.png` and `ui-labels.png` are captures of the `default` and `labels` fixtures at frame 5 of 8, 1280×720, with the environment `tests/ui_regression.rs` gives its runs. They are taken on the reference machine at its OS scale of 1.75 (Xft.dpi 168), with the packaged fonts, from the repository root after a debug build:

```bash
cargo build -p example-05-ui-lab --locked
env -u TUNGSTEN_CAPTURE_DIRECT TUNGSTEN_UI_LAB_FIXTURE=default TUNGSTEN_UI_LAB_POST=off TUNGSTEN_RENDER_POST_AA=off TUNGSTEN_SMOKE_FRAMES=8 TUNGSTEN_CAPTURE_FRAME=5 TUNGSTEN_CAPTURE_RESOLUTION=1280x720 TUNGSTEN_CAPTURE_PATH=examples/05_ui_lab/tests/fixtures/ui-visual.png target/debug/example-05-ui-lab
env -u TUNGSTEN_CAPTURE_DIRECT TUNGSTEN_UI_LAB_FIXTURE=labels TUNGSTEN_UI_LAB_POST=off TUNGSTEN_RENDER_POST_AA=off TUNGSTEN_SMOKE_FRAMES=8 TUNGSTEN_CAPTURE_FRAME=5 TUNGSTEN_CAPTURE_RESOLUTION=1280x720 TUNGSTEN_CAPTURE_PATH=examples/05_ui_lab/tests/fixtures/ui-labels.png target/debug/example-05-ui-lab
```

`just visual` then compares them at tolerance 0. Regenerate them only for a change that means to move the lab's pixels, and say why in the change.
