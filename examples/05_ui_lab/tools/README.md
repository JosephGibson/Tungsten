# Example 05 sprites

`frame.png` (48×48, nine-slice insets 12 px, declared on the sprite entry) and `icon.png` (32×32) are generated by `generate.py`, standard library only: it writes the PNG chunks by hand, so no Pillow is needed. Run it from the repository root:

```bash
python3 -B examples/05_ui_lab/tools/generate.py          # rewrite both files
python3 -B examples/05_ui_lab/tools/generate.py --check  # exit 1 when a file differs
```

The frame's four corners carry accent marks inside the inset, so a stretched nine-slice shows whether the corners kept their source size. Edit the generator, not the PNGs; the generated files are checked in because `just repo-check` covers them as ordinary assets.
